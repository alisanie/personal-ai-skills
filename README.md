## Skills

- **Laravel Issue Writer** — [`skills/laravel-issue-writer/SKILL.md`](skills/laravel-issue-writer/SKILL.md): turn a request, review report, or repository finding into a focused Laravel issue written primarily in Persian.

- «با Laravel Issue Writer این مشکل را تبدیل به Issue کن.»

Use the linked `SKILL.md` as the source of truth in each environment.
